# Task 2 - Car Selling Price Prediction

## Project Overview

This project predicts the selling price of used cars using Machine Learning.

Developed as part of the ShadowFox AI/ML Internship.

---

## Dataset

The dataset contains information about used cars including:

- Car Name
- Present Price
- Kilometers Driven
- Fuel Type
- Seller Type
- Transmission
- Owner
- Car Age

Target Variable:
- Selling Price

---

## Machine Learning Pipeline

### Data Preprocessing
- Removed duplicates
- Feature engineering
- Created Car Age feature
- One-hot encoding
- Data cleaning

### Models Tested

- Linear Regression
- Random Forest Regressor
- Gradient Boosting Regressor

### Final Model

Gradient Boosting Regressor was selected as the final model.
